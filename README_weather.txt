РЕШЕНИЕ ЗАДАНИЯ: погода для городов из Cities.txt

Файлы:
- weather.py — скрипт (Python 3.9+; внешние библиотеки не нужны).
- Cities.txt — исходный список городов.
- test_weather.py — локальные тесты без доступа к интернету.

Запуск:
1. Разместите weather.py и Cities.txt в одной папке.
2. Откройте терминал в этой папке.
3. Выполните: python weather.py
